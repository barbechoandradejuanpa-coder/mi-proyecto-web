# Guía para crear una nueva aplicación

## Preparación

Copia `apps/plantilla/` y asigna un nombre breve con minúsculas y guiones. Define en una frase qué podrá hacer el estudiante al terminar.

## Contenido mínimo

- Título y objetivo de aprendizaje.
- Instrucción inicial breve.
- Contenido dividido en bloques pequeños.
- Una interacción que obligue a decidir, ordenar, calcular o interpretar.
- Retroalimentación que explique por qué una respuesta es correcta.
- Fuentes y fecha de actualización si contiene recomendaciones clínicas.

## Calidad docente

Antes de publicar, comprueba:

- [ ] El objetivo es observable y evaluable.
- [ ] El lenguaje corresponde al nivel del estudiante.
- [ ] Los casos son ficticios o están completamente anonimizados.
- [ ] La retroalimentación enseña y no se limita a “correcto/incorrecto”.
- [ ] No se presentan herramientas educativas como sustituto del juicio clínico.
- [ ] Las referencias clínicas están vigentes y claramente identificadas.

## Calidad técnica

- [ ] Funciona sin errores al abrir `index.html`.
- [ ] Se adapta a 390 px de ancho y a escritorio.
- [ ] Puede utilizarse con teclado.
- [ ] Los controles tienen etiquetas claras.
- [ ] El contraste permite leer cómodamente.
- [ ] No guarda datos sensibles en `localStorage`.
- [ ] No contiene secretos, tokens ni contraseñas.
